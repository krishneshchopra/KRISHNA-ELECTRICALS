INSTALL ON ANDROID:
1. Upload this folder to a static web host (for example GitHub Pages).
2. Open the HTTPS site in Chrome.
3. Chrome menu (⋮) -> Add to Home screen / Install app.
4. It will appear like an app on the phone.

This package is a PWA, not a signed APK. A signed APK requires an Android build/signing step.
